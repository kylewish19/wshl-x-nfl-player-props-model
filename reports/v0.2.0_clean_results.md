# v0.2.0 Clean Challenger Results

This report supersedes the invalidated v0.1.0 validation numbers.

## Chronology
- Development: 2021-2023
- Specification/feature selection: 2024
- Untouched final test: 2025
- Live refit after specification freeze: all completed rows through the current 2026 refresh

## Selected champions

| Prop | Feature set | Algorithm | 2025 final-test metric |
|---|---|---|---|
| QB passing yards | enriched | Random Forest | MAE 66.46 yd; RMSE 84.04 |
| QB passing TDs | baseline | Poisson GLM | Poisson deviance 1.142; MAE 0.903 TD |
| QB rushing yards | baseline | Elastic Net | MAE 11.45 yd; RMSE 15.46 |
| RB rushing yards | baseline | Elastic Net | MAE 18.84 yd; RMSE 27.84 |
| WR/RB receiving yards | baseline | Elastic Net | MAE 16.24 yd; RMSE 23.43 |
| Player 1+ sack | enriched | Hist Gradient Boosting | Brier 0.1331; log loss 0.4215; AUC 0.7264 |

## What v0.2 taught us
- Extra snap/NGS/PFR context improved specification selection for QB passing yards.
- Advanced defensive/snap context also improved the sack classifier.
- More features did not improve QB passing TDs, QB rushing, RB rushing, or receiving yards on the 2024 selection set. Those props therefore remain on the simpler baseline feature set.
- Model complexity was also rejected for several yardage targets: Elastic Net beat the tree models in chronological selection for QB rush, RB rush, and receiving yards.
- The live system should continue to treat each prop as a separate ML problem rather than sharing one universal model/feature recipe.

## Data freshness
The training refresh contained 97,010 player-stat rows and 252,618 play-by-play rows from 2021-2026. Current-season player stats were present through 2026 Week 2 at the time of this run.
